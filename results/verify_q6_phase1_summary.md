# Q6 破坏-重建机制消融验证摘要（阶段一）

## 实验设计

- 规模：512x16、1024x32（generate_synthetic_matrix, seed=42, heterogeneity=1.0）
- 初解：round_robin、min_min；预算：5000、10000 次评估
- 三组对比（K=4, R=2, S=4，Q5 最优配置）：
  - A: bottleneck_local_search（基线）
  - B: bottleneck_local_search_dr（strict 接受准则，默认参数 destroy_frac=0.2, segment_evals=1000, max_stagnation=3）
  - C: bottleneck_local_search_dr（metropolis 接受准则，其余同 B）

## 阶段一结果

- 单元格总数：8
- B 相对 A 平均改进率差值：-7.47pp；B 更优 0 格、劣化 4 格、其余持平
- C 相对 A 平均改进率差值：-7.47pp；C 更优 0 格、劣化 4 格、其余持平

按初解/预算拆分的平均 B-A（pp）：

| 初解 | 5000 | 10000 |
|---|---|---|
| round_robin | -14.30 | -15.60 |
| min_min | +0.00 | +0.00 |

## 阶段二触发判定

- B-A 平均 -7.47pp（劣化格 4/8） → 不满足触发条件（< +1.0pp），不进入阶段二

## 机制有效性演示（三节点循环陷阱实例）

- 构造：60 任务、3 节点，P 按组循环 roll [1,5,9]，错配初解（每组全部放在最慢节点）
- 初解 c0 = 180.00
- 单次瓶颈搜索：收敛于 c = 70.00（I = 61.11%），仅用 760 evals 即耗尽邻域（给 100000 预算也只用了这么多，无法自行逃逸）
- DR strict（seed=1）：c = 20.00（I = 88.89%），首次超越单次局部最优于累计 280 evals（3 次全局改善，19 段）
- DR strict（seed=2）：c = 24.00（I = 86.67%），首次超越单次局部最优于累计 200 evals（2 次全局改善，12 段）
- DR strict（seed=3）：c = 24.00（I = 86.67%），首次超越单次局部最优于累计 240 evals（2 次全局改善，12 段）

## 结论

阶段一未观察到 DR 相对基线的正贡献：随机合成实例上，
min_min 初解下瓶颈搜索的局部最优盆地唯一且深（扰动重搜始终回到同一局部最优），
round_robin 初解下切段破坏扰乱了尚未收敛的下降进程（segment_evals 越小越明显）。
陷阱实例证明破坏-重建机制本身有效（能逃离单次搜索无法逃出的局部最优），但在典型随机实例上没有用武之地。
论文定位建议：作为边界讨论报告——DR 仅在存在深局部最优结构的实例上有价值，
对随机均匀实例无贡献；保留实现与参数接口作为未来工作。
