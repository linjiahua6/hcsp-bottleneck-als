# 实验 C：真实主实验配对显著性检验

- 数据来源: results/real_main.csv（112 个配对）
- 检验方法: 符号检验（binomial test，scipy 未安装）
- H0: plain 与 bottleneck 的 c_final 无差异；
- 配对定义: 同 (filepath, 规模, 初解, 预算) 的 plain/bottleneck c_final；|diff| <= 1e-09 计为平局；
- 符号检验: X ~ Binomial(n_pairs, 0.5)，p = 2 * min(P(X <= n_better), P(X >= n_better))；n_pairs 为非平局配对数。

## 整体检验（全部配对）

- 配对总数: 112；bottleneck 严格更优: 112；平局: 0；劣化: 0
- p_value = 3.85186e-34（sign）
- 结论: p < 0.05，**拒绝 H0**——整体 112/112 的瓶颈优先优势在统计上显著。

## 说明

- 符号检验是 Wilcoxon 的无分布替代（对差异幅度不敏感，只利用方向）；两者结论一致时更稳健。
- 分组检验中 2048x64 每组 8 对；显著性解读以整体检验为主。
